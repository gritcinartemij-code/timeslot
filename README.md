# TimeSlot — полноценный локальный MVP

## Что это
Это уже не просто макет. Проект содержит:
- Node.js HTTP-сервер без внешних npm-зависимостей;
- регистрацию и вход;
- сессии через cookie;
- хеширование паролей через встроенный `crypto.scrypt`;
- профили специалистов;
- услуги и цены;
- создание свободных временных слотов;
- публичные страницы специалистов;
- бронирование слотов;
- личный кабинет;
- сохранение данных в `data/db.json`;
- адаптивный интерфейс.

## Запуск
Нужен Node.js 18+.

В папке проекта:
```bash
node server.js
```
Затем откройте:
http://localhost:3000

## Важно
Это полноценный MVP для разработки и локального тестирования, но НЕ готовый production-сервис.
Перед публичным запуском нужны:
- HTTPS;
- настоящая БД;
- резервное копирование;
- rate limiting;
- CSRF/XSS/security hardening;
- email/Telegram/SMS уведомления;
- восстановление пароля;
- подтверждение контактов;
- реальные платежи;
- юридические документы;
- политика обработки персональных данных;
- корректная настройка домена и хостинга;
- проверка требований к деятельности несовершеннолетнего владельца.

Не храните production-пароли и персональные данные в JSON-файле.
